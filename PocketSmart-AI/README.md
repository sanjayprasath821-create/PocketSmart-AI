# PocketSmart AI

PocketSmart AI is a GenAI-powered budget and recommendation
assistant for:

- Home Interior Planning
- Party Planning
- Jewelry Recommendations
- Optional jewelry outfit image analysis
- User authentication
- Recommendation history
- Gemini AI integration
- REST APIs
- Responsive web UI

---

# Technology Stack

Backend:

- Python
- FastAPI
- SQLAlchemy
- SQLite
- Pydantic

Frontend:

- HTML
- CSS
- JavaScript
- Jinja2

AI:

- Google Gemini
- google-genai SDK

Testing:

- pytest
- FastAPI TestClient
